Instructions — Créer un Personal Access Token
ÉTAPE 1
Connectez-vous sur github.com puis allez dans :
Settings → Developer settings → Personal access tokens → Fine-grained tokens
ÉTAPE 2
Cliquez sur Generate new token. Donnez-lui un nom (ex: plan-manager), une expiration, et sélectionnez votre repo dans Repository access.
ÉTAPE 3
Dans Permissions → Repository permissions, activez Contents → Read and write.
ÉTAPE 4
Cliquez Generate token, copiez le token (il ne sera affiché qu'une seule fois) et collez-le ci-dessous.
